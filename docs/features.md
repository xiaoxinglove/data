# 功能与验收清单

人工维护目标、验收标准和计划命令；自动验证器维护通过结果。
F001 包含验证器实现及自测；验证器出现前保持“未验证”，不得人工标 passing。
验证器须按单元、集成、端到端顺序执行，任一步失败即停止并返回非零退出码；全部通过才写入 passing、时间和被验证代码版本。源码已改动时旧结果只能视为历史证据。

## F001 目标契约（待实现，不代表当前 API 行为）

- 计划安装命令：uv sync --locked。依赖及锁文件纳入版本控制，在干净环境验证。
- 计划启动命令：uv run uvicorn app.main:app --host 127.0.0.1 --port 8008。
- 计划完整验证命令：uv run python scripts/check.py。脚本、工具和测试目前均待实现。
- /health 使用合法访问令牌返回 200 和 status=healthy；只代表进程存活，不代表 RAG 就绪。
- /chat 使用合法访问令牌及 {"query":"你好"} 返回 200，query="你好"，context 和 documents 为列表；没有真实检索时 status=not_implemented，不得固定声称 completed。
- /chat 缺 query、空白 query 或非字符串 query 返回 422。
- 受保护接口缺凭据或无效令牌返回 401；有效身份缺少所需权限返回 403。
- 渠道尚未实现时，/enterprise/{channel} 通过认证授权后返回 501，不能声称 accepted=true 代表业务处理成功。
- API 拒绝行为在集成层验证；端到端层启动真实进程，通过 HTTP 重现合法、非法请求及服务关闭流程。
- 验证器自测覆盖：任一层失败不运行后续层、不写 passing；全部成功才写 passing。
- 实现身份边界前，在 DECISIONS.md 明确签发方、令牌校验方式及权限映射。测试凭据必须可控，不得假冒生产身份提供方。
- README 记录经验证的安装、启动、请求示例和占位限制。

## F002 验收方向

真实资料检索和回答、来源可追溯、无资料时明确说明。激活前确定资料集、准确率指标和具体阈值，不在 F001 中声称通过。
