# 数据访问规范

当前没有真实数据库实现或已采纳的存储选型。

- 关系数据库使用 SQLAlchemy 2.0 风格 Core/ORM 接口、参数化查询，并明确提交、回滚和连接生命周期。
- 禁止通过字符串拼接把用户输入写入 SQL；必要的原生 SQL 仍须参数绑定。
- 向量库、图数据库和缓存使用对应客户端，不要求通过 SQLAlchemy。
- 数据访问模块接收可信身份、租户和资源范围，并在实际读取和写入时执行权限限制。
- 缺少安全上下文时默认拒绝；不能依赖生成回答后再过滤来防止数据泄露。
- 迁移或破坏性变更说明影响和恢复方式，并遵守任务授权范围。
- 密钥、令牌和密码不进入业务日志或记忆；允许保存的用户数据须定义用途、保留期和删除方式。
